# 云数据库权限与索引配置

> 这是**上线前必须完成的人工步骤**：云开发集合权限无法由仓库代码强制，只能由控制台配置并复核。

## 1. 集合清单与权限矩阵

| 集合 | 用途 | 权限（控制台「数据库 → 集合 → 权限设置」） | 客户端直连 |
|---|---|---|---|
| `game_users` | 用户游戏快照（`_id = openid`） | **所有用户不可读写，仅云函数（服务端 SDK）可读写** | 禁止 |
| `game_audit_logs` | 审计日志（只写） | **所有用户不可读写，仅云函数可写** | 禁止 |
| `game_rate_limits` | 频率限制计数 | **所有用户不可读写，仅云函数可读写** | 禁止 |
| `Users`（旧） | 迁移期只读兼容 | 设为「所有用户不可读写」；确认迁移完成后删除集合 | 禁止 |

配置完成后，在小程序全局搜索确认**不存在** `wx.cloud.database()` 调用；所有读写只经 `wx.cloud.callFunction({ name: "game" })`。

> 为什么不用「仅创建者可读写」：本项目不需要客户端直连数据库，权限越窄越安全。若某天需要直连，请先做安全评审再单独放开某个集合，且必须保证文档 `_openid` 与查询条件由平台自动隔离。

## 2. 索引

在控制台为下列字段建立索引：

| 集合 | 字段 | 类型 | 说明 |
|---|---|---|---|
| `game_audit_logs` | `expireAt` | **TTL 索引** | 90 天自动清理审计日志 |
| `game_rate_limits` | `expireAt` | **TTL 索引** | 限流窗口过期自动清理 |
| `game_audit_logs` | `ts` | 普通（降序） | 按时间排查 |
| `game_users` | `updatedAt` | 普通（降序） | 运维扫描、备份核对 |

`_id` 为主键，无需额外索引。限流集合 `_id = sha256 风格哈希(openid|action|window)`，本身即唯一键。

## 3. 云存储权限

- 音频资源、二维码文件：**私有读**，客户端通过 `wx.cloud.getTempFileURL` 换取有时效链接。
- 二维码 `cloudPath` 格式 `qrcode/{openidHash}/{requestId}.png`，避免不同用户互相覆盖（旧实现固定 `code.png`）。
- 不要在客户端代码里硬编码长期有效的临时链接。

## 4. 备份

- 开启云数据库自动备份，保留 ≥ 7 天。
- 每次发布前手动导出 `game_users` 快照（控制台 → 数据库 → 导出）。
- 迁移期保留旧 `Users` 集合导出文件，作为回滚数据源。
